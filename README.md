OtpravkaApi

Описание проекта:

OtpravkaApi — это REST-сервис для отправки электронных писем с возможностью формирования и прикрепления отчёта о выполненной операции.
Сервис принимает запрос на отправку письма, выполняет отправку через SMTP-сервер, сохраняет информацию об операции в журнале и предоставляет методы для просмотра истории и статистики отправок.

Процедура запуска проекта:

Локальный запуск:

1. Открыть проект в Visual Studio.

2. Убедиться, что установлена платформа .NET 8 SDK.

3. В файле appsettings.json указать SMTP-настройки:
 адрес SMTP-сервера;
порт;
 логин;
 пароль приложения.

4. Запустить проект (F5).

Запуск в облаке (Amvera):

Доступ к сервису осуществляется по домену Amvera через Swagger UI.

Описание API и методов:

1. GET /api/EmailReport

Назначение:
 Возвращает журнал всех операций отправки писем.

Формат запроса:
 Без параметров.

 2. POST /api/EmailReport/send

Назначение:
Основной бизнес-метод сервиса.
Отправляет электронное письмо, формирует CSV-отчёт и прикрепляет его как вложение.

Формат запроса (JSON):

{
  "recipient": "user@example.com",
  "subject": "Отчёт",
  "body": "Текст письма"
}

В случае ошибки отправки статус будет Failed, а поле errorMessage будет содержать текст ошибки.

3. GET /api/EmailReport/stats

Назначение:
Возвращает агрегированную статистику по всем отправкам.

Формат запроса:
Без параметров.

4. Корневой маршрут /

Назначение:

При обращении к корню сервиса выполняется перенаправление на Swagger UI для удобного тестирования API.
