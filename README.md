OtpravkaApi

OtpravkaApi — это веб-сервис, разработанный на платформе ASP.NET Core Web API, предназначенный для отправки электронных писем и формирования отчётов об их отправке.

Сервис принимает данные письма (получатель, тема, текст), отправляет email через SMTP-сервер и фиксирует результат выполнения операции в виде отчёта, доступного через REST API.

Назначение сервиса:

Основная задача сервиса — предоставить простой REST API для:
отправки электронных писем;
формирования и хранения отчётов об отправке;
получения истории и статистики операций.

Функциональные возможности:

отправка email-сообщений;
формирование отчёта об операции отправки;
хранение отчётов в памяти приложения;
получение списка отчётов;
получение статистики по операциям;
тестирование API через Swagger UI.

Архитектура:

Сервис реализован в виде REST API без пользовательского интерфейса.
Для взаимодействия и тестирования используется Swagger (OpenAPI).

Доступные эндпоинты:

POST /api/EmailReport/send — отправка письма и формирование отчёта
GET /api/EmailReport — получение всех отчётов
GET /api/EmailReport/stats — получение статистики работы сервиса

Развёртывание:

Проект может быть запущен локально или развёрнут в облачной среде Amvera.
Для публикации используется конфигурационный файл amvera.yml.

Используемые технологии:

ASP.NET Core Web API (.NET 8)
REST API
Swagger (OpenAPI)
SMTP (MailKit)
Git, GitHub
